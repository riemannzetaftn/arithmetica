title: Section 1. Categories
---

In this section we define categories.

!!! definition "Category"

    A *category* $\sf{C}$ consists of

    - A set of its *objects*, denoted by $\Ob(\sf{C})$, and
    - For each pair $(A,B)$ of its objects, a set of the *morphisms* from $A$ to $B$, denoted by $\Hom_{\sf{C}}(A,B)$.
    { #def-category }
