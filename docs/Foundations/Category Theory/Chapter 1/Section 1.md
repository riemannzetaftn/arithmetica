---
title: Section 1. Categories
---

In this section we define categories.

!!! definition "Category"

    A *category* $\mathsf{C}$ consists of

    - A set of its *objects*, denoted by $\mathrm{Ob}(\mathsf{C})$, and
    - For each pair $(A,B)$ of its objects, a set of the *morphisms* from $A$ to $B$, denoted by $\mathrm{Hom}_{\mathsf{C}}(A,B)$.
    { #def-category }
